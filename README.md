# فعاليات (Activities)

Arabic party games for friend groups: **Imposter**, **Guessing**, **Countries** and **Mafia**, on one phone or online.

**Live:** https://imposter.my

## Run locally

```sh
npm install
npm run dev     # http://localhost:8080
npm test
```

## Deploy

Every push to `main` deploys to Vercel (`imposter.my`, `www.imposter.my`, `new.imposter.my`).
The Lovable project syncs with this repo, so edits made there land here too.

## Stack

React 18, TypeScript, Vite, Tailwind, shadcn/ui, Supabase (Postgres, Realtime, Edge Functions), Vercel.
